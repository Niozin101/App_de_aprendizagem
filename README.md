# Caderno de Estudos

App de estudos em uma única página (HTML, CSS e JavaScript, sem dependências).

- **Inglês:** textos em inglês com tradução ao clicar em cada frase e perguntas de compreensão.
- **Estudo:** cronômetro de 1 hora; o dia só é marcado como concluído quando ele chega a zero. Calendário e sequência de dias.
- **Dev:** quizzes de JavaScript, Python, Java, C, SQL, HTML/CSS, TypeScript e Go.

O progresso fica salvo no `localStorage` do navegador.

## Como usar

Abra o `index.html` no navegador.
